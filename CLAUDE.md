# astro-versions-proxima

Astro integration package that provides a version badge (header) and footer text component for Astro sites.

## Project structure

```
src/
  types.ts                  — all shared TypeScript interfaces (VersionsProximaOptions, WidgetConfig, etc.)
  index.ts                  — public entry: re-exports versionsProxima + all types
  integration/
    index.ts                — Astro integration factory: reads package.json, resolves version, injects Vite define
  runtime/
    config.ts               — getWidgetConfig(), buildHeaderText(), buildFooterText() — used by .astro components at runtime
    format.ts               — formatUtcDateTime(), formatOffsetLabel() — pure date/time formatting
  components/
    VHeaderBadge.astro      — <span> version badge component
    VHeaderBadge.d.ts       — Props types for VHeaderBadge
    VFooterText.astro       — <p> footer text component
    VFooterText.d.ts        — Props types for VFooterText
dist/                       — compiled output (generated by tsup, not committed)
  index.mjs + index.d.ts
  runtime/config.mjs + config.d.ts
```

## Build

```bash
bun run build       # compile TypeScript → dist/ via tsup
bun run typecheck   # type-check without emitting
```

Build uses **tsup** with two entry points:
- `src/index.ts` → `dist/index.mjs` (main integration + all exports)
- `src/runtime/config.ts` → `dist/runtime/config.mjs` (imported by .astro components at runtime)

The `.astro` components import from `../../dist/runtime/config.mjs` (relative to `src/components/`).

## Release / publish

Releases are **automated via GitHub Actions** (`.github/workflows/publish-npm.yml`):
- Triggers on every push to `main`
- Runs `bun run build`
- Auto-bumps **patch** version with `npm version patch`
- Pushes the version commit + tag back to main
- Publishes to npm with `NODE_AUTH_TOKEN` secret

For a **manual minor/major release**, bump the version locally before pushing:
```bash
npm version minor   # or major
git push && git push --tags
```
Then the workflow will auto-bump patch on top of that on the next push — to skip this and publish exactly what's there, use `/release` skill.

### Required secrets

| Secret | Description |
|--------|-------------|
| `NPM_TOKEN` | npm access token with publish rights to `@proxima812` scope |

## Key design decisions

- **No bundler for source**: `.mjs` source files were used before; now TypeScript source compiles to `dist/` via tsup.
- **Vite define injection**: `__AVP_WIDGET_CONFIG__` is replaced at build time by Astro's Vite step — declared as `declare const` in `src/runtime/config.ts`.
- **Components stay in `src/`**: `.astro` files are shipped as-is; they import from the compiled `dist/runtime/config.mjs`.
- **`external: ["astro"]`**: astro is a peer dep, not bundled into dist.
